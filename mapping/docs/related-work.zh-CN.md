# 相似按键映射方案

[English](related-work.md)

资料核对日期：2026-10-27。以下是可比较的思路，不是本项目的依赖，也未作为替代方案实测。

- [DS5 Mapper](https://github.com/MathiasMl/ds5-mapper)：作者为英雄联盟 WASD 开发的 Windows/macOS DualSense 键鼠映射器，包含重映射和陀螺仪瞄准。本项目提供 Steam 原生 VDF，右手使用真实鼠标；没有复制该项目代码。
- [左手手柄＋右手鼠标](https://www.reddit.com/r/leagueoflegends/comments/1ql129f/started_playing_league_with_a_controller_in_my/)：作者把 8BitDo 摇杆映射到 WASD，以肩键/背键施法，配合鼠标侧键。整体使用方式与本方案很接近，设备和具体按键不同。
- [左 Joy-Con＋鼠标](https://www.reddit.com/r/leagueoflegends/comments/1pdxd7r/playing_wasd_using_left_joycon_and_mouse/)：作者用 BetterJoy 和 JoyToKey 实现单手控制器配鼠标，是同类玩法的另一例。

这些资料说明这种玩法已有先例，不能据此认定键位完全相同、当前版本兼容或已获 Riot 认可。
