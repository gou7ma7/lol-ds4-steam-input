# Related mapping work

[简体中文](related-work.zh-CN.md)

Sources checked on 2026-10-27. These are comparable ideas, not dependencies or tested replacements.

- [DS5 Mapper](https://github.com/MathiasMl/ds5-mapper): the author built a Windows/macOS DualSense keyboard/mouse mapper for LoL WASD, with remapping and gyro aim. This project instead ships a native Steam VDF and uses a real mouse in the right hand. No code was copied from DS5 Mapper.
- [Left-hand controller + right-hand mouse](https://www.reddit.com/r/leagueoflegends/comments/1ql129f/started_playing_league_with_a_controller_in_my/): the post author describes an 8BitDo joystick mapped to WASD, shoulder/paddle skill buttons, and mouse side buttons. The overall physical play style is very close, with different controls/hardware.
- [Left Joy-Con + mouse](https://www.reddit.com/r/leagueoflegends/comments/1pdxd7r/playing_wasd_using_left_joycon_and_mouse/): the author uses BetterJoy and JoyToKey for a one-handed controller plus mouse. It provides another example of this hybrid play style, using a different mapping stack.

These sources establish that the play style has precedents. They do not establish identical button mappings, current compatibility or Riot approval.
