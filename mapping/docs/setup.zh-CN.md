# 键位与游戏设置

本方案的工作顺序是：**手柄 → Steam 输出键盘键 → 英雄联盟 WASD 模式中的技能动作**。使用时左手拿手柄，右手拿鼠标。

## 必须先以管理员身份启动 Steam

> [!IMPORTANT]
> **在应用和使用这套 LoL 桌面映射前，必须以管理员身份启动 Steam。** 原使用者已确认，普通权限启动的 Steam 在这套方案中无法控制游戏。请把这一步作为必做前提。

1. 保存 Steam 中的操作，通过 **Steam → 退出** 或托盘菜单完全退出。仅关闭窗口可能仍有 Steam 进程在运行。
2. 右键 Steam 快捷方式或 `steam.exe` → **以管理员身份运行**，确认 Windows 提示。普通权限的 Steam 仍在运行时，再打开一次快捷方式并不能可靠地提升原进程权限。
3. 连接手柄，应用桌面布局，再按下文配置英雄联盟 WASD 键位。
4. 进入训练模式，让英雄联盟获得焦点，验证移动和技能。如果桌面映射正常、进入游戏却无响应，先检查实际运行的 Steam 是否以管理员身份启动。

Windows 会限制不同进程完整性级别之间的输入注入，微软 [SendInput 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput) 说明了 UIPI 限制。这与使用者报告的现象一致；上述必做步骤来自这套环境的实际反馈，不代表所有 LoL 安装都必然需要提权。权限检查与 VDF、游戏键位配置分别处理。

此步骤针对 Steam 输入映射。独立振动、灭灯程序的构建和运行不需要管理员权限；仓库脚本不会自动提升 Steam 权限或修改 Windows 权限设置。

## 核心左手操作

- 左摇杆向上 / 下 / 左 / 右 → W / S / A / D → 移动。
- L2 左扳机 → 键盘 E → Q 技能。
- L1 左肩键 → 左 Shift → W 技能。
- L3 左摇杆按下 → 键盘 R → R 技能。
- 鼠标右键 → 游戏直接接收鼠标右键 → E 技能。

上述最终技能分配由方案使用者确认。Steam 布局本身不包含英雄联盟内部的 WASD 按键设置，也不保存真实鼠标或鼠标驱动的侧键设置。

## 英雄联盟设置

进入游戏的 WASD 操作设置，而不是只改传统右键移动模式的 QWER。

1. 启用 WASD 移动，保留 W/A/S/D 作为方向键。
2. Q 技能对应 E 键。
3. W 技能对应左 Shift。
4. E 技能对应鼠标右键。
5. R 技能对应 R 键。
6. 按自己的鼠标安排侧键的召唤师技能、装备等操作。

本机读取到的 WASD 全局配置明确包含 Q → E、E → 鼠标右键；W → 左 Shift 和 R → R 的最终行为由使用者确认。游戏可能只保存相对默认值的差异，不能只查看传统模式的 `evtCastSpell*` 字段判断这套设置。

[wasd-keybinds.reference.json](../game-settings/wasd-keybinds.reference.json) 是项目自己的键位参考格式，**不是 Riot 的可导入配置**。请通过游戏设置界面手动配置，避免用整份 `PersistedSettings.json` 覆盖他人的设置。

## 原生文件中保留的其他绑定

以下按当前有效预设解析，公开文件保留它们，以便完整备份。核心玩法只需要左半边。

- 十字键上 → 1；右 → 2；下 → 3；左 → 4。
- Share → Tab；Options → Esc。
- × → Space；○ → E；□ → R；△ → F。
- R1 → 鼠标滚轮向上。
- R2 → E，绑定在 trigger 的 `click` 输入；L2 的 E 绑定在 `edge` 输入。
- R3 → R；右摇杆保留原有输出设置（`output_joystick = 2`）。
- 中央触控板 → 鼠标模式；按下 → 鼠标左键。

原布局里还有未启用的旧触控板组。公开文件保留原有启用关系，没有把未启用组当作当前操作。绑定中的 `Jump`、`Use`、`Reload` 等文字来自早期模板，是显示标签，不表示英雄联盟实际动作。

## 持续大招与英雄差异

方向键下在原布局中输出 **3**。如果要用它施放持续 R，需要把对应英雄的 R 技能设成 3；原生文件没有自动把方向键下改成 R。

其他英雄差异和 Ctrl + 左键交互见 [使用备注](usage-notes.zh-CN.md)。振动程序不执行或改变这些键位。
