# 英雄与交互备注

## 持续施放 R

部分英雄需要持续施放或引导 R。按下左摇杆 L3 时容易顺带推动摇杆，让角色产生移动并中断大招；可以改用**方向键下**释放 R。

原生 Steam 布局的方向键下输出键盘 **3**，因此推荐在游戏内为对应英雄把 R 技能改到 3，保留全局的 L3 → R。这个选择需要手动设置，没有加入自动切换逻辑。

## 按英雄调整鼠标右键

- 提莫、卡牌等英雄的 E 是被动技能，鼠标右键可以分配给更常用的主动技能。
- 如果 Q 或 W 需要高频释放，也可以把该技能单独映射到鼠标右键，再安排被替换技能的位置。
- 使用游戏提供的单英雄 WASD 设置保存差异，避免每次切换英雄都改全局设置。

默认方案仍是 L2 → Q、L1 → W、鼠标右键 → E、L3 → R。这些例外不会在振动程序中硬编码。

## 冰霜传送门与目标选择

按方案使用者的实际体验，这种模式下，某些原本直接点击物体完成的操作，例如使用冰霜传送门，以及之后选择落点，需要 **Ctrl + 鼠标左键** 才能生效。

遇到类似点击目标或确认落点的交互时，可尝试这组操作。这里记录的是这套 WASD 操作模式下的使用经验，不是对所有版本、模式和交互的统一保证。

这是操作备注：项目不会自动发送 Ctrl、点击鼠标或选择传送落点。
