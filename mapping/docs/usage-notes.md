# Champion and interaction notes

[简体中文](usage-notes.zh-CN.md)

## Sustained or channelled R

Clicking L3 can accidentally push the left stick, move the champion and cancel a sustained ultimate. Use **D-pad down** instead for affected champions. The exported layout emits **3**, so change that champion's R binding to 3 in the game; keep the global L3→R setup.

This is manual configuration, not automatic champion switching.

## Per-champion mouse right button

- Teemo and Twisted Fate have passive E skills; assign the mouse right button to a more useful active skill.
- If Q or W needs frequent use, move it to the mouse right button and choose another control for the displaced skill.
- Use per-champion WASD settings rather than repeatedly changing the global setup.

Global defaults remain L2→Q, L1→W, Mouse right→E, L3→R. No automatic swaps are implemented.

## Frost Gates and destination selection

In the user's actual setup, some interactions that normally involve clicking an object, including Frost Gates and then choosing a destination, require **Ctrl + left mouse button**.

Try that combination for similar target/confirmation interactions. This records the user's experience in this WASD setup, not a guarantee for every game version/mode or interaction. The project does not automatically send Ctrl/clicks or select a destination.
